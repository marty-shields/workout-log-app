# Lists

## `ListRow`
A full-width row of text. With `OnClick` it is a button ending in a muted chevron `Icon`; without, plain text.
- `data-testid`: `TestId`.

## `StatTile`
A number with a label, on a card. The number uses `--color-accent` at `--font-size-xxl`.
- `data-testid`: `TestId`.

## `EmptyState`
A message in a dashed box, for a list or section with nothing in it.
- `data-testid`: `TestId`.
