# Security policy

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/marty-shields/workout-log-app/security/advisories/new). Do not open a public issue for it.

Include the version (Settings, or the release tag), what you did and what happened. This is a personal project: expect a reply in a few days, and a fix in the next release where one is needed.

Only the latest release is supported.
